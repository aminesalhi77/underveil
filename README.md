# Underveil

A 3D voxel survival game. Dig deep. Build. Survive.

Built with Godot 4 + GDScript.

## Status

Phase 1 — walking skeleton. Character movement, dual camera, world scaffold.

## Controls

| Action | Key |
|---|---|
| Move | W A S D |
| Look | Mouse |
| Jump | Space |
| Sprint | Shift |
| Toggle 1st/3rd person | V |
| Free mouse | Esc |

## Dev

Requires Godot 4.4+.

```bash
godot --path .
```
